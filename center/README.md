# `center/` — Central Reports & Decision Artifacts

## Roadmap Position
Pipeline stage 6 (reporting): the human-readable decision artifacts — conviction
scores, lane summaries, audit reports, and valuation-alpha results. Read-mostly;
the `valuation_alpha/` subfolder mirrors `opencode_scripts/output/` results.

## Folder Summary
Report markdown + JSON results: `conviction_scores.md` /
`conviction_model_output.json`, `hybrid_quant_500.md`, lane reports
(`lane_gamma.md`, `lane_summary.md`, `lane_delta_metadata.json`,
`lane_gamma.md`), audits (`data_audit_report.md`, `scraper_audit_report.md`,
`data_completeness_audit.md`, `backfill_integration_verification_*.md`),
`PsychologicalPillar.md`, `weight_reasoning.md`, and
`valuation_alpha/` (allocator/bias/sleeve reports + results.json).

## Skeleton
```
center/
  conviction_scores.md  hybrid_quant_500.md  lane_gamma.md  lane_summary.md ...
  valuation_alpha/   # allocator_report.md bias_ablation_report.md results.json ...
  *.json             # conviction_model_output.json lane_delta_metadata.json ...
```

## Files (key)

| File | Purpose |
|---|---|
| `conviction_scores.md` / `conviction_model_output.json` | conviction model output |
| `hybrid_quant_500.md` | hybrid 500 report |
| `valuation_alpha/` | valuation-alpha evaluations (results.json, reports) |
| `scoring_metrics.md` | metric definitions used in scoring |
| `weight_reasoning.md` | rationale for fusion weights |

## Entrypoints
None (report artifacts). Regenerated by `valuation_alpha/pipeline.py` and
`opencode_scripts/eval_googl_valuation_alpha.py`.

## Dependencies
`valuation_alpha/`, `Qualitative/psychological/`, `discovery/`, `data/backtests/`.

## Efficient Pathways
- `full_pipeline`: final executive checks read these artifacts; keep JSON
  side-by-side with markdown so the LLM layer can cite numbers precisely.
