## 2. OOS validation (mandatory)

- **Stable-dividend basket**: `audit_basket` uses ONLY dividend history at/under
  the decision date and `price.asof(date)`; a name enters only once its own 5y
  window qualifies (no-lookahead, verified by test). Bills-fallback dominates
  2018-2020 while the 5y window builds (25 of 102 decisions).
- **Cut gate**: compares COMPLETE calendar years only; the partially-elapsed
  current year is excluded (removes a partial-year false-cut artifact found in
  first run, regression-tested).
- **Opportunistic overlay**: `_trailing_z` uses price history at/under the date
  within the trailing 5y window, min 250 observations. Fired ZERO times in the
  sim — reported as falsification evidence, NOT retuned.
- **Macro state + covariance**: unchanged from Phase 1 (90d trailing median /
  200d trailing SMA; 252d window + 21d embargo). Execution at the first trading
  day strictly after the decision date (purge+embargo discipline).
- **DIVIDEND strategy target** re-evaluates the basket at every monthly decision
  date on data strictly <= that date; the friction gate must clear before any
  trade executes.

## 3. Multi-source demonstration

- Prices: yfinance + **Nasdaq public API** cross-check (Phase-1 results
  unchanged: SPY/GLD 0.999-1.000, others >=0.92, BIL/SGOV raw-level corr 1.000).
- Dividends (Phase-2 second source): SEC XBRL
  `CommonStockDividendsPerShareDeclared` cross-check via
  `valuation_alpha/datastore/xbrl_financials.py` + `cik_resolver.py`, wired in
  `fee_sim3.main()`. **SEC EDGAR/CIK unavailable this run** -> the cross-check
  degraded to NA and printed SKIPPED (documented, same pattern as the Phase-1
  FRED fallback). The yfinance dividend feed is disk-cached and fully
  populated (13/13 tickers, 46-47 quarterly payouts each; "O" 139 monthly
  payouts — consistent with a monthly-paying REIT, which the ticker exclusion
  removes).
- Dividend feed robustness: yfinance returns tz-aware ex-dates; the fetcher
  normalizes to naive (regression-tested). A 0.6s pace between tickers avoids
  Yahoo throttling (observed: burst fetch returned 0/13).

## 4. Outcome summary (auditor note, not a recommendation)

- BASELINE SPY $31,700 (+217%), Sharpe 0.83, maxDD -33%.
- MACRO $22,982 (+130%), Sharpe 1.38, maxDD -15%, 6 trades.
- MINVAR $24,719 (+147%), Sharpe 1.43, maxDD -14%, 6 trades.
- DIVIDEND (Phase-2) $14,188 (+42%), Sharpe 1.33, maxDD -6%, 1 trade (initial
  deployment only), fees $25 = 0.60% of gains, dividends $1,406 = **56x
  coverage**. 102 decisions: 25 bills-fallback / 77 stable-dividend basket
  (avg 5 names); opportunistic overlay fired 0 times.
- Coverage hypothesis CONFIRMED across all four strategies (45-71x).
- DIVIDEND is the safest sleeve (Sharpe 1.33, maxDD -6%) but the lowest raw
  return (+42%) in a US-large-cap-dominated window — expected for a defensive
  high-dividend basket. The opportunistic engine contributed nothing this
  window (its pre-registered z-gate never tripped); that is the falsification
  result, not a defect to tune.

## 5. Caveats

1. SEC XBRL cross-check degraded to NA this run (EDGAR/CIK unreachable); must
   be exercised and reported when SEC EDGAR is reachable.
2. FRED macro unreachable -> macro signal is the price-proxy fallback (unchanged
   from Phase 1); re-run + re-report when FRED returns.
3. Dividend yields remain static annual estimates; the audit independently
   verifies the basket's genuine 5y+ payout stability, but the coverage figure
   uses the pre-registered static yields.
4. The opportunistic overlay's 0-firing result is on one window (2018-2026); it
   is a pre-registered gate, not evidence the concept is dead.
