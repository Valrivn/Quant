# Implementation Plan — Phase 1 (B-20260803-003, ruling D-20260803-003 APPROVE)

Post-debate draft. Phase 1 only; Phase 2 (opportunistic + dividend engines) is a
separate brief after Phase 1 passes the conductor gate.

## Scope (Phase 1)
1. Bonds + gold sleeves (extend existing `diversification/` L2 module).
2. Gradient-descent-like risk minimizer across ALL assets (equity sleeves +
   bonds + gold) — objective: min portfolio risk, friction-bounded.
3. Macro-state allocator: bull -> buy cheaper bonds/alternatives; bear -> buy
   cheap stocks; opportunistic gains run through the regime overlay.
4. Auditor-gated $10k sim vs baseline + one theoretically-better strategy,
   with dividend-fee-coverage measured.
5. Multi-source data (not only yfinance).

## Data layer (multi-source, reuse-first)
- **Equities**: yfinance (existing `valuation_alpha/datastore/prices.py`) PLUS
  the 100-name discovery universe from `universe/discovery.py`.
- **Bonds**: FRED (existing `diversification/datastore.fetch_fred_series` via
  FREDScraper) for yields (BAA10Y, DGS10) + a bond ETF (BND/TLT) as tradable
  sleeve; SEC EDGAR already in the repo for issuer fundamentals.
- **Gold**: GLD/IAU already in `diversification/datastore.py`; cross-check
  against a non-yfinance spot series (FRED GOLDPMGBD228NLBM or similar) so the
  sleeve is not yfinance-only.
- **Macro state**: FRED BAA10Y credit spread (already cached in pilot) +
  DGS10 + a market regime series; state machine validated OOS.
- **Dividend screen inputs**: SEC XBRL dividends + price yields via a second
  source (not yfinance-only) — deferred data prep, but the sim must ingest a
  stable-dividend basket definition in Phase 1 to MEASURE coverage.

## Modules to build (mirror existing module layout)
- `diversification/sleeves.py` — bond/gold sleeve assembly + weights.
- `diversification/risk_minimizer.py` — gradient-descent-like optimiser over
  asset covariance; **friction-bounded** (weights change only when expected
  risk reduction clears the rebalancing fee, per D-20260803-002 rule); no
  hardcoded weights; explicit covariance-estimation window + shrinkage as
  *parameters*, never constants baked into selection.
- `diversification/macro_state.py` — regime classifier (spread/rate thresholds
  as *pre-registered* gates, not fit); emits state-contingent target shifts:
  bull -> tilt bonds/alternatives, bear -> tilt cheap stocks.
- `diversification/fee_sim3.py` — $10k implementation-today sim reusing the
  share-accounting engine from the D-20260803-002 `fee_sim.py` (already
  cross-validated to pilot totals), extended to multi-asset + macro overlay +
  dividend income accrual.

## $10k simulation spec (auditor-gated)
- Compare: (a) **baseline** = SPY buy-and-hold; (b) **Phase 1 strategy** =
  equity sleeves + bonds + gold under macro-state allocator + risk minimizer;
  (c) **one theoretically-better strategy** (e.g., a risk-parity-weighted
  variant or a fixed "all-weather" 60/40 with fee-aware rebalance) — pre-picked
  in the brief, not chosen after seeing results.
- Outputs: end value, total gain, total fees, **fees as % of gains**,
  **dividend income vs reallocation fees (the CEO's coverage hypothesis)**,
  Sharpe, maxDD, IR, trades, per-asset weights.
- Window: 2018-2026 monthly, mirroring the validated pilot harness.

## Auditor gate (hard requirement, D-20260803-003)
- Audit pass required BEFORE any result is reported: no hardcoded weights,
  picks, or params in the backtest; all thresholds are config + pre-registered.
- **OOS validation mandatory**: risk-minimizer covariances and macro-state
  thresholds must be estimated on expanding windows (purge+embargo), never on
  the full window — same discipline as D-20260803-001/002.
- College recorder logs the results as adaptive evidence.

## Definition of done (from brief SUCCESS)
1. Bonds + gold sleeves live in `diversification/`.
2. Risk minimizer across all assets, friction-bounded.
3. Macro-state allocator (bull->bonds/alternatives, bear->cheap stocks).
4. $10k sim vs baseline + better-theoretical strategy; auditor certifies no
   hardcoding; OOS validation shown.
5. Dividend-fee-coverage measured and recorded.
6. Multi-source data demonstrated (>=1 non-yfinance source per asset class).
7. Conductor gate >=90% pass, 0 new failures.

## Sequencing & gates
1. Data layer + multi-source checks -> tests.
2. sleeves.py + macro_state.py -> tests.
3. risk_minimizer.py -> auditor (no-hardcoding + OOS) -> tests.
4. fee_sim3.py $10k sim -> auditor -> results.
5. College recorder logs sim + coverage ratio.
6. Conductor gate -> report to CEO.
7. Phase 2 brief (opportunistic + dividend engines) only after 1-6 green.

## Phase 2 (deferred, NOT in this build)
Opportunistic stock engine (reuse D-20260803-002 swap rule), dividend engine +
stable-dividend audit, dividend-engine integration into the sim. Greenlit when:
Phase 1 conductor pass AND dividend-fee-coverage recorded.
