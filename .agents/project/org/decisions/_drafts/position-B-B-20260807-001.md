- POSITION: IG/TikTok should operate as an INDEPENDENT discovery channel decoupled from Reddit to maximize alternative alpha generation, which is practical only if we stop gating new signals behind degraded legacy sources.
- REASONS:
  1. The CEO explicitly intended IG to be independent; gating it behind Reddit multi-source validation bottlenecks discovery and defeats the purpose of finding non-consensus alpha.
  2. The P2 ranker already supports independent weighting (sum_src w_src * norm_rank_src), so the architecture natively supports decoupled scoring without requiring multi-source overlap.
  3. Given the RM-FINAL baseline edge comes from regime/fee discipline rather than alpha, unlocking independent, uncorrelated social streams (IG/TikTok) is the most viable path to actually injecting alpha into the system.
- RISKS:
  1. Relying on a single independent source (like TikTok) increases vulnerability to coordinated spam or algorithmic manipulation if sanitizers fail.
  2. Retail-lag on social video platforms could result in entering trades too late, creating anti-alpha.
- BLIND-SPOTS: I did not verify the specific Reddit/StockTwits scraper implementations or how easily new credentials can be provisioned. I am assuming the P1 census "all gated" status implies structural degradation rather than just missing API keys.
