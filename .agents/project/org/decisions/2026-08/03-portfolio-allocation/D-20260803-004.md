# D-20260803-004 — Phase 2: opportunistic + dividend engines (APPROVE hybrid + floor)

- **Tier:** 3
- **Date:** 2026-08-03
- **Brief:** B-20260803-004
- **Ruling:** APPROVE (hybrid + minimum-candidates floor)

## Options considered
1. Position A (big-pickle): new DIVIDEND strategy variant in fee_sim3, reused
   D-20260803-002 absolute-swap/liquidate-only rule as-is on the equity sleeve,
   >=10y stable-dividend audit window, four-step build this round.
2. Position B (gemini-planner): stable-dividend audit first as a pure funding
   overlay, fresh bear-regime opportunistic definition acting on large-caps only
   and deferred, 5y audit window.
3. Hybrid (hermes-bridge S-20260803-004): A's DIVIDEND-variant structure + B's
   5y audit window + reused swap rule with a pre-registered bear-regime gate
   appended, plus a minimum-candidates floor with a bills fallback so the sim
   cannot starve in 2018-2022 (approved).

## Positions
- **big-pickle:** Position A — four-step build (stable-dividend audit module,
  opportunistic engine reusing the swap rule, DIVIDEND variant integration,
  then OOS/auditor/coverage/conductor); 10y payout window; >=3% yield floor;
  REIT/BDC/MLP excluded; SEC XBRL cross-checked vs Nasdaq/yfinance price yields.
- **gemini-planner:** Position B — 5y unbroken payout (arithmetically feasible
  from 2018 inside expanding windows); fresh multi-asset opportunistic
  definition tied to the bear regime, large-cap only; cash-sweep overlay
  integration; special dividends excluded.

## Disagreement map
- Substantive: audit window (5y vs 10y), integration (variant vs overlay),
  opportunistic rule (reuse vs fresh/bear-regime).
- Consensus: pre-registered thresholds, no hardcoding; multi-source dividend
  validation; OOS purge+embargo; auditor + coverage re-measure + conductor gate;
  small-cap floor preserved.

## Synthesis (hermes-bridge)
- Recommendation: hybrid — A's four-step DIVIDEND-variant structure + B's 5y
  audit window + reused swap rule with a pre-registered bear-regime gate appended
  (no redefinition, no deferral). Risk: 5y window may yield thin candidates in
  2018-2022; without a minimum-candidates floor with a bills fallback the sim can
  starve.

## CEO ruling
> APPROVE hybrid + floor

**Rationale:** CEO accepted the recommended hybrid and, consistent with his
falsification-first + measured-not-assumed pattern, took the flagged risk
seriously: the minimum-candidates floor with a bills fallback is included in the
pre-registered config, not left to runtime luck. The 5y window wins on
arithmetic feasibility; the reused swap rule with the bear-regime gate appended
preserves D-20260802-002's fee-aware liquidate-only discipline without a risky
redefinition.
