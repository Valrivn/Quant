# D-20260808-004 — High-Scale Proxy & Session Rotation Configuration for Instagram Reels

- **Tier:** 3
- **Date:** 2026-08-08
- **Brief:** B-20260808-003
- **Ruling:** APPROVE

## Options considered
1. Single IP and single account session configuration (default, prone to bot bans at scale).
2. Dynamic Proxy Rotation (`config/proxies.txt`) and Multiple Account Session Pool Loader (`config/instagram_sessions/*.json`) with random/rotational selection (proposer: CEO).

## Positions
- **big-pickle:** Support proxy and session directory loaders to safely scale crawls to 100k-1M Reels without triggering IP/account bans.
- **gemini-planner:** Support hybrid structure with silent fallbacks to single session files if session pool or proxies are missing.

## Disagreement map (if T3)
- Disagree on: None (consensus reached on configuration loader).
- Consensus on: Protecting accounts from bans via rotating residential proxies and account sessions.

## Synthesis (hermes-bridge, if T3)
- Recommendation: Approve implementing proxy/session directory loaders in the scraper configurations.
- Rationale: Directly enables large-scale dynamic crawling while maintaining full compatibility with the existing single-account structures.

## CEO ruling
> Approve and implement the high-scale configuration. Dynamically read proxies from `config/proxies.txt` and load cookies from a pool of files under `config/instagram_sessions/*.json`, rotating them when rate limits are hit.

**Rationale:** Safely executes the 100k to 1M Reels discovery crawl while mitigating security/anti-bot risks.
