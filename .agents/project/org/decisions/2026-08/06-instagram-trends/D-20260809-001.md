# D-20260809-001 — Scaling Instagram Reels Scraper to 100,000+ Videos with Anti-Bot Measures

- **Tier:** 3
- **Date:** 2026-08-09
- **Brief:** B-20260809-001
- **Ruling:** APPROVE

## Options considered
1. Single-threaded local scraping with static delays and a single account (prone to rapid bot bans and rate-limits).
2. Distributed asynchronous scraper architecture targeting the personalized Reels feed using irregular delays, residential proxy rotation, and a pool of 100+ active account sessions.

## Positions
- **big-pickle:** Support moving to a distributed, proxy-rotated worker architecture with session pool management to reach 100,000+ videos safely.
- **gemini-planner:** Support the distributed model but emphasize decoupling the scraper pipeline from the slower audio transcription task using a task queue.

## Disagreement map
- Disagree on: None.
- Consensus on: Implementing a decoupled pipeline using a pool of 100+ scraper accounts, residential proxy rotation, and GPU-driven asynchronous audio transcription.

## Synthesis (hermes-bridge)
- Recommendation: Approve the transition to a distributed, decoupled scraper architecture.
- Rationale: Scale of 100k+ Reels is mathematically impossible without proxy/session rotation, and decoupling ensures scraping is not throttled by slower Whisper transcription nodes.

## CEO ruling
> Approve. Implement the distributed Reels scraping architecture with a pool of 100+ accounts, residential proxy rotation, irregular delays (5-15s) to avoid bot detection, and a decoupled GPU task queue for Whisper audio transcription to scale to 100,000+ videos.

**Rationale:** Crucial to safely scale the alternative data discovery pipeline to 100,000+ Reels while avoiding anti-bot countermeasures and rate limits.

## Effect
- Blueprint delta: Update discovery pipeline specification to support distributed async scraping, proxy pools, and decoupled GPU Whisper workers.
