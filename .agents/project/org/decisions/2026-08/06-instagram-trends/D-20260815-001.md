## Positions
- **big-pickle:** APPROVE Hybrid A+B — build a weekly IG_LLM crawler/LLM-synthesis pipeline that programmatically constructs qualitative proxy scores (moat, sentiment, product reviews) as structured DB columns under the IG_LLM_ prefix, feeding the existing qualitative gate rather than bypassing it, then re-run rm-final as the go/no-go checkpoint.
- **gemini-planner:** Approve the IG_LLM Sentinel Validation pipeline, provided the LLM proxy outputs are strictly typed and structurally penalized for hallucination before feeding into the qualitative gate.

  1. Hallucination mitigation depth — A calls for source-URL grounding + human-readable audit trail per score; B calls for strict typing + structural penalties.
  2. Scope guardrails — A explicitly hard-prohibits gate threshold changes in the same PR; B does not raise this constraint.
  3. Token/cost budget — B flags weekly LLM synthesis token costs as a primary risk; A does not assess pipeline budget impact.
  4. Entity-resolution — B flags small-cap ticker collision risk; A does not address it.
- Consensus on:
  1. Building the IG_LLM crawler/synthesis pipeline (both APPROVE).
  2. Proxy scores flow INTO the existing qual gate — gate is never bypassed or weakened.
  3. IG_LLM_ ticker prefix for isolated provenance; DB-first persistence.
  4. RFF256 (IC 0.054) is the target signal to unlock.
  5. LLM hallucination passing the qual gate is the top shared risk.

## Synthesis (hermes-bridge, if T3)
- Recommendation: Hybrid — approve build with four mandatory implementation constraints: (1) structured output schema + source-URL grounding + per-score audit trail (A+B combined hallucination controls); (2) hard-prohibition on gate threshold changes in the same PR; (3) datasource-worker token-cost estimate before build starts; (4) ticker-collision validation step in the crawler.
- Disagreements:
  - Substantive: Hallucination mitigation mechanism (A: URL grounding + audit trail; B: strict typing + structural penalties) — both are necessary, implementation brief must mandate both.
  - Substantive: Token/cost budget impact (B flags it; A ignores it) — weekly LLM synthesis costs are unbounded without a pre-build estimate.
  - Substantive: Entity-resolution / ticker collision (B flags it; A ignores it) — a missed collision silently corrupts provenance.
  - Stylistic: Gate guardrail language — A codifies it explicitly; B omits it but does not contradict.
- Rationale: Both positions approve the same pipeline; the only real fight is over which safety controls are "enough." The risk of a false qual-gate pass outweighs the extra complexity of combined hallucination controls, and the token-cost concern is the strongest underweighted risk in A and must be resolved before building.
- Risk: LLM hallucination passing the qual gate is unmitigated until structured schema + URL grounding + audit trail are all in the implementation brief simultaneously.
